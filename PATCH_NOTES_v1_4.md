# Patch v1.4

Visual and readability update:

1. Bullet speed reduced from 260 to 150.
2. Bullet radius increased from 4.0 to 5.5.
3. Bullet rendering now has:
   - drop shadow
   - black outline
   - main color body
   - darker inner shade
   - white highlight
   This makes bullets visually distinct from flat territory cells.
4. Control chamber text is larger and more obvious:
   - font size 20
   - centered above each chamber
   - outline added
   - format changed to: 蓝方 本轮 8 发
