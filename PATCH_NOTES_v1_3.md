# Patch v1.3

User-requested UI and start flow update:

1. Added a start menu before entering the game.
2. The start menu allows choosing the square grid size: 20x20, 30x30, 40x40, or 50x50.
3. Changed visible UI text to Chinese:
   - faction names
   - pending shot labels
   - score text
   - title
   - release gate text
4. The battlefield, turrets, and chambers are positioned dynamically according to the selected grid size.
5. Removed remaining integer division warnings in Battlefield.gd and Gate.gd.
