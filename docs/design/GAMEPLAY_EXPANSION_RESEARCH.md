# 玩法扩展研究：从球球战争到物理战争沙盒

Date: 2026-11-27
Role: design research input / 设计研究输入，不是实现承诺
Status: 评分为主观设计判断；未做原型、未做性能验证、未逐款试玩竞品

本文回答一个问题：`BallWar` 能否从球球战争复刻，发展成具有长期可玩性、可观赏性和自由实验空间的物理战争沙盒。

结论是扩展空间很大：现有四阵营、倍率仓、炮台、领土格、事件系统，已经构成五个可独立扩展又相互影响的玩法系统。品类也不必局限在「球球战争」，弹珠机、自动战斗、塔防、领土策略、肉鸽构筑、人工生命模拟都有可借鉴机制。

本文是设计与参考输入，不改变 `ROADMAP.md` 的进度承诺；是否落地、何时落地以 `docs/ROADMAP.md` 为准。

## 4. 九大扩展方向 / Nine directions

### 方向一：倍率仓变成可构筑的兵工厂（优先研究）

目前控制仓基本是「×2 或发射」。可引入功能钉、特殊门与火力存储。

| 新机制 | 效果 | 玩法价值 |
|---|---|---|
| +10 | 增加固定弹量 | 早期稳定收益 |
| ×2 / ×3 | 倍增弹量 | 高风险高收益 |
| 储存门 | 保存部分弹量至下一轮 | 持续积蓄火力 |
| 修复门 | 弹量转化为炮台生命 | 攻防取舍 |
| 分裂钉 | 落球临时分为两个 | 连锁触发 |
| 强化钉 | 为下一轮炮弹附加效果 | 构筑组合 |
| 回流门 | 弹珠返回上方 | 增加蓄能机会 |
| 超载门 | 巨额加成但消耗生命 | 风险博弈 |

一个阵营选修复门 + 储存门，另一个选高倍率 + 超载门，即使炮台相同也会产生完全不同的战争风格。

事件层已有 `+10 / ×2 / ×3 / 加球 / 短路`（见 `scripts/EventRouletteController.gd` 的 `EFFECT_*` 常量），因此真正的新内容不是底层能力，而是让这些机制成为控制仓内部**可组合**的规则。

### 方向二：炮弹之间真正发生战争

现有炮弹只攻击领土与炮台，双方弹幕缺少交互。可让两股弹流正面相撞：相互抵消、质量吞噬、偏转、护盾弹拦截、强化弹击穿。

不建议数千刚体全量两两碰撞，可用空间哈希或网格分桶，只检测邻近敌方弹珠。它既提升视觉冲击，也让防御有意义：炮台不必抢在攻击前占满领土，还可以用弹幕抵挡。

### 方向三：领土不再只是颜色和分数

当前每格价值相同。可给格子加功能：

| 领土类型 | 功能 |
|---|---|
| 普通领土 | 决定占领率 |
| 能源格 | 为所属阵营提供资源 |
| 工厂 | 定期生成额外弹珠 |
| 要塞 | 需多次攻击才能占领 |
| 炮台据点 | 占领后成为己方辅助火力 |
| 修复站 | 为所属阵营炮台提供恢复 |

这样会出现真正有价值的战略位置：黄方只占 20% 但握有两座兵工厂和一个中央炮台，蓝方占 50% 却无特殊设施，蓝方未必占优。

经济机制容易滚雪球。第一版建议只加**可争夺炮台**，不急着做完整资源体系。

### 方向四：四角炮台扩展成战争设施

从四门炮互射，走向每个阵营多设施：主炮台（进攻）、拦截塔（抵消弹幕）、兵工厂（产弹）、修复塔（维持防线）、重炮基地、传送站。

其中最重要的是**可摧毁、可占领的辅助炮台**：战场中央的中立炮台被绿色占领后立刻向其他阵营开火，这比事件转盘更直观地改变战局。

### 方向五：阵营数量与战争关系

经典 1v1v1v1、联盟 2v2、围攻 1v3、六国混战、八国混战、联合讨伐 BOSS。

最推荐 **BOSS 战**：不是中央炮台十倍血量，而是分阶段——普通连射 → 环形护盾 → 旋转弹幕 → 狂暴。四阵营既要合力打 BOSS，又可争夺领土、抢最后一击；可做合作也可做竞争。相比单纯加到八阵营，非对称战斗更容易产生不同的观赏体验。

### 方向六：物理战场环境

反射墙（改变弹幕路径、形成防御死角）、引力核心（弹流走弧线）、传送门（远距离突破）、旋转障碍（持续改变安全区）；还可加速度带、减速区、可破坏墙体、弹性反射器、单向通道、随机风场。

原则：**地图本身参与战争，而不是一张被涂色的平板。**

### 方向七：事件系统从数字奖励升级为战场灾变

| 事件 | 战场效果 |
|---|---|
| 重力风暴 | 所有弹珠向中央偏转 |
| 极限狂暴 | 全场弹珠速度短暂提升 |
| 防御时代 | 所有炮台获得临时护盾 |
| 战场裂变 | 部分弹珠自动分裂 |
| 冰封区域 | 局部区域弹珠减速 |
| 空降援军 | 弱势阵营获得临时炮台 |
| 反射风暴 | 战场出现旋转反射墙 |
| 能量过载 | 所有炮台进入快速发射状态 |
| 领土断裂 | 特定区域变成中立争夺区 |
| 最终决战 | 战场逐渐收缩，迫使交战 |

不建议默认加入大面积强制交换领土这类事件：它刺激，但会让前几分钟的战斗失去意义。好的随机事件应改变接下来的战斗条件，而不是直接替玩家决定胜负。

### 方向八：肉鸽战争构筑

玩家支持一方，每隔一段时间从三个随机能力中选一个。示例（数值为设计示意）：

- 弹幕分裂数量流：普通弹珠 20% 概率额外生成一颗
- 钢铁要塞防御流：炮台最大生命 +30% 并回复部分当前生命
- 超载兵工厂倍率流：倍率门额外 +1 级，但每次释放消耗炮台生命

多次升级后可能形成不同流派：

| 流派 | 核心思想 |
|---|---|
| 弹海流 | 依靠数量淹没敌人 |
| 重炮流 | 少量高质量炮弹集中突破 |
| 防御流 | 拦截、护盾、修复，等待反攻 |
| 扩张流 | 优先占领特殊资源格 |
| 赌倍率流 | 承受风险，等一次超大规模爆发 |
| 连锁流 | 靠分裂与碰撞连续触发 |

自动观战模式下也可让四个 AI 自行选择强化，形成不同阵营构筑。

### 方向九：战争沙盒与自定义编辑器（长期核心）

参考 Physion、Algodoo 等，把现有规则交给玩家配置：

| 配置项 | 示例值 |
|---|---|
| 参战阵营 | 4 |
| 战场大小 | 60 × 60 |
| 每方初始控制球 | 3 |
| 倍率仓倍率 | ×2 / ×3 / ×4 / ×5 / ×10 |
| 模拟速度 | 0.5× / 1× / 2× / 4× |
| 战场规则 | 炮弹相互碰撞、领土产生资源、允许特殊炮弹、允许阵营复活、启用随机事件、启用联盟与背叛 |
| 战场总格数 | 3,600（自动计算） |
| 初始控制球总数 | 12（自动计算） |

它让玩家自己提问：8 门小炮能否战胜 1 门超级重炮？高倍率对高射速谁更强？两支防御型军队能否击败四支攻击型军队？这与《全面战争模拟器》类的核心乐趣一致——**玩家设计实验，物理系统给出结果。**

## 5. 八种可独立成立的模式 / Mode candidates

| # | 模式 | 玩法重点 |
|---|---|---|
| 01 | 经典战争 | 保留原版：四阵营、倍率释放、领土争夺 |
| 02 | 史诗战争 | 大地图、多阵营、多炮台、高密度弹幕 |
| 03 | 阵营构筑 | 局内三选一强化，发展流派 |
| 04 | BOSS 讨伐 | 多阵营合力攻击有阶段机制的超级炮台 |
| 05 | 要塞攻防 | 一方守大型要塞，一方突破多层防线 |
| 06 | 领土争霸 | 争夺工厂、能源格、中立炮台，建立战争经济 |
| 07 | 战争锦标赛 | 多阵营多轮自动战争决出冠军 |
| 08 | 自由沙盒 | 自定义阵营、地形、武器、控制仓与规则 |

这是长期产品规划，不是要求一次性实现八套系统。

## 7. 下一批实验 / Next experiments

先做独立实验，不急着合入经典模式；每个实验都要有**关闭开关**，保留经典模式作为对照，重点验证新规则是否产生了新的战斗体验，而不是只让系统更复杂。

| 实验 | 内容 | 难度预估 | 预期价值 |
|---|---|---|---|
| E01 | 储存门、修复门 | 低至中 | 验证控制仓扩展能力 |
| E02 | 敌方弹珠碰撞抵消 | 中至高 | 形成真实弹幕交锋 |
| E03 | 中央可占领炮台 | 中 | 形成战场战略目标 |
| E04 | 反射墙与旋转机关 | 中 | 验证物理地图乐趣 |
| E05 | 四阵营强化三选一 | 中 | 验证构筑与阵营差异 |
| E06 | 中央超级炮台 BOSS | 中至高 | 验证非对称战争 |

最值得期待的是 **E01 + E02 + E03** 的组合：它们分别改变**火力生产**、**火力交锋**、**火力部署**；三者连通后会形成新的战争循环。
