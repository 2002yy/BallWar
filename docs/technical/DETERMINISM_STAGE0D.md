# 阶段 0D · 对局随机数分流

分支基于已经和美术 #22 对齐的 DEV-SPEED #26。每次开始对局创建一个 MatchRandom。固定种子可重开相同开局，默认开局从系统熵取得新种子。

| 随机来源 | 归属 |
|---|---|
| 控制球落点、初速度、钉柱碰撞、卡球与短路扰动 | 每阵营控制仓 |
| 炮台初始相位 | 每阵营炮台 |
| 炮弹首次炮台命中检测偏移 | 每阵营炮弹 |
| 转盘效果、阵营选择与间隔 | 对局事件 |
| 配色 | 表现层独立流 |

同一主种子的各流由固定派生规则创建，创建顺序和其他流的调用次数不影响该流。探针比较各模拟流的内部状态，待触发事件只比较影响时间与规则的字段。

## 验证

Windows Godot 4.7.1，40×40、中画质基础局。

- 启动与加载成功，12 个现役测试、两个 DEV-SPEED 专项和新增的 8 项随机数测试通过。
- 12345、23456、34567 三个种子，分别用 1× 经典配色对比 20× 随机配色，三组到 tick 5100 的模拟摘要一致。随机配色实测为霓虹、糖果、暗夜。
- 种子 12345 的五档加速到 tick 5100 摘要一致。
- 种子 12345、2× 真实窗口，实测 60 与 15 FPS 的轨迹到 tick 5100 一致。两轮首次事件均在 tick 4047 生效。
- 种子 12345 的 300 秒无头 1×/20× 摘要一致，覆盖 tick 0–18000。

同一个种子在此次分流后会产生新的轨迹和事件结果。当前存档继续使用原格式。恢复已有存档时随机数内部状态尚待持久化验证。不同画质使用相同模拟预设、跨机器以及 Android 行为各有独立验收范围。
